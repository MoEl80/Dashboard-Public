# Dashboard-Public

Public display repository for safe, generated Forex analysis and dashboard output.

## Architecture

`MoEl80/Forex-Analysis-Cloud` remains private and is the source of truth for OANDA access, technical and fundamental analysis, CFTC sentiment, central-bank communication analysis, economic-event risk, and final recommendations.

Only explicitly generated and sanitized dashboard files and market-analysis data may be published here. Do not add API tokens, credentials, account IDs, environment files, logs, GitHub Actions secrets, or other sensitive information.

GitHub Pages serves the public dashboard from the `main` branch.
